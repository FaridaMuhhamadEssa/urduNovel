# 🌸 urduNovel 📚

Welcome to **urduNovel**, a website for Urdu novel lovers.

## ✨ About the Project
urduNovel is a simple and beautiful website dedicated to Urdu novels and literature. It allows readers to explore the wonderful world of Urdu stories.

## 🎀 Features
- 📚 Explore Urdu novels
- 🌸 Beautiful Pink and White design
- 📖 Discover interesting stories
- 💗 Simple and user-friendly interface

## 🛠️ Technologies Used
- HTML
- CSS

## 🎯 Purpose
The purpose of this project is to share the beauty of Urdu literature and make reading Urdu novels enjoyable for everyone.
